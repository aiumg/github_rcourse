Thresholds and the ROC Curve

Every cut-off is a decision about which error you prefer

1 The threshold is the test

In this chapter

  • Trace how sensitivity and specificity move as the cut-off changes
  • Construct and read an ROC curve
  • Interpret the area under the curve, and state what it does not tell you
  • Choose a threshold from the clinical cost of each error rather than by default

Chapter 1 imposed a cut-off of 14 ng/L and moved on. That number did more work than any other decision in this course. Change it and every measure changes with it.

2 Two overlapping distributions

The reason a perfect threshold does not exist is visible in the raw data. Patients with and without infarction have different troponin distributions — but the distributions overlap.

Why overlap is unavoidable

If the two distributions separated cleanly, a threshold in the gap would give 100% sensitivity and 100% specificity, and diagnosis would be a solved problem. Biological variation, assay imprecision and heterogeneous disease guarantee the overlap. Choosing a threshold means choosing where in the overlap to stand.

3 Sweeping the cut-off

cutoffs <- c(5, 10, 14, 20, 30, 50, 100)

sweep <- t(sapply(cutoffs, function(k) {
  tk <- dtx_table(cohort$troponin_ng_L >= k, cohort$mi_confirmed)
  mk <- dtx_measures(tk)
  c(cutoff = k, TP = tk$tp, FP = tk$fp, FN = tk$fn, TN = tk$tn,
    sensitivity = round(mk$sensitivity, 3),
    specificity = round(mk$specificity, 3),
    PPV = round(mk$ppv, 3))
}))

Read the sensitivity and specificity columns against each other. There is no row where both improve. That constraint is what the ROC curve draws.

4 The ROC curve

Plot the true positive rate against the false positive rate at every possible cut-off, and you get the receiver operating characteristic curve.

The curve is a summary of the whole family of tests you could build from one measurement. Moving along it towards the upper right buys sensitivity with specificity; moving down-left does the reverse.

5 Area under the curve

roc <- dtx_roc(cohort$troponin_ng_L, cohort$mi_confirmed)
auc <- dtx_auc(roc)
round(auc, 3)
[1] 0.953

The AUC here is 0.953. Its interpretation is specific and often misquoted: it is the probability that a randomly chosen diseased patient has a higher test value than a randomly chosen patient without the disease (Hanley and McNeil 1982).

What AUC does not tell you
  • It is not accuracy. It is threshold-independent, so it says nothing about how the test performs at the cut-off you will actually use.
  • It ignores clinical cost. Two tests with identical AUC can differ completely in the region of the curve that matters for your decision.
  • It ignores prevalence. A test with an excellent AUC can still have a hopeless PPV in a low-prevalence setting, as Chapter 3 showed.

Report the AUC. Then report sensitivity, specificity and predictive values at the threshold you intend to use, which is the number a clinician can act on.

6 Choosing a threshold honestly

The Youden index (\(J = \text{sensitivity} + \text{specificity} - 1\)) picks the point furthest above the diagonal.

youden <- sapply(sort(unique(cohort$troponin_ng_L)), function(k) {
  mk <- dtx_measures(dtx_table(cohort$troponin_ng_L >= k, cohort$mi_confirmed))
  mk$sensitivity + mk$specificity - 1
})
best <- sort(unique(cohort$troponin_ng_L))[which.max(youden)]
best
[1] 21.9

Youden treats a false negative and a false positive as equally bad. In acute coronary syndrome they are not remotely equal: a missed infarction may be fatal, while a false positive costs an admission and an angiogram. Weight the errors and the optimum moves.

The rule-out strategy

This is why emergency departments run troponin as a rule-out test with a low threshold, accepting many false positives to drive false negatives towards zero. The threshold encodes a value judgement about which error the department is willing to make. Making that judgement explicit is better practice than inheriting a cut-off from the assay insert.

7 Check yourself

Test A has an AUC of 0.91; test B has an AUC of 0.88. Which conclusion is justified?

AUC averages across all thresholds. ROC curves can cross, so test B may well dominate in the high-sensitivity region where a rule-out test operates. And neither AUC says anything about predictive value, which depends on prevalence.

You lower the troponin threshold from 14 ng/L to 5 ng/L. Which pair of changes follows necessarily?

A lower threshold calls more patients positive. More diseased patients are caught, so sensitivity rises; more healthy patients are wrongly flagged, so specificity falls. Compare the rows for 5 and 14 in the sweep table above and you can watch it happen.
