Diagnostic Test Accuracy

Reading a test result the way the evidence requires

Author

Institute of Medical Education

Published

9 September 2026

A 58-year-old man arrives in the emergency department with chest pain. His high-sensitivity troponin comes back at 22 ng/L, above the laboratory cut-off. Does he have a myocardial infarction?

The test does not answer that question. It shifts a probability. How far it shifts, and from where, is what this course is about.

Everything below rests on one small table. In our teaching cohort of 600 patients presenting with chest pain, 77 were eventually confirmed to have had an infarction. Comparing the troponin result against that final diagnosis gives:

MI confirmed MI excluded Total
Test positive 74true positive 148false positive 222
Test negative 3false negative 375true negative 378
Total 77 523 600

Two cells the test got right, in teal. Two it got wrong, in rose. Every measure in this course — sensitivity, specificity, predictive values, likelihood ratios, the ROC curve — is a ratio built from those four numbers. That colour convention holds on every page, so you can always see at a glance which part of the table a formula is reading.

By the end of this course you will be able to

  • Construct a 2×2 table from raw clinical data and name each cell correctly
  • Calculate sensitivity, specificity, predictive values and likelihood ratios, with confidence intervals
  • Explain why predictive values change with prevalence while sensitivity and specificity do not
  • Choose a diagnostic threshold that reflects the clinical cost of each type of error
  • Interpret an ROC curve and say what the area under it does and does not tell you

How this course works

Each chapter mixes explanation, worked calculation and practice. The code that produces every number and figure is shown on the page — you can read it, copy it, and run it on your own data. Nothing is hidden in a spreadsheet.

Work through the chapters in order the first time. Afterwards each one stands alone as a reference.

Try it now

Every chapter ends with questions like this one. Choose an answer and the page tells you whether you were right and why.

In the table above, the 3 patients in the lower-left cell are those whose troponin was below the cut-off but who turned out to have had an infarction. What are they called?

They are false negatives: the test was negative, the disease was present. These are usually the errors that matter most clinically, because the patient is reassured and sent home. Chapter 4 looks at how lowering the threshold trades false negatives away in exchange for more false positives.

Before you start

What you need

The course reads perfectly well in a browser with no software installed. To run the code yourself you need R, RStudio and the knitr package. No other packages are required — everything uses base R.

About the data

The 600-patient cohort used throughout is simulated. It behaves like a real chest-pain population and is fine for learning, but no clinical conclusion should be drawn from it. You can download the dataset and work with it directly.
