The 2×2 Table

Where every accuracy measure comes from

In this chapter

  • Turn a continuous measurement into a binary test result
  • Build a 2×2 table against a reference standard
  • Name all four cells and both margins without hesitating
  • Recognise the three errors that most often corrupt such a table

1 The reference standard comes first

A diagnostic test is never assessed on its own. It is compared against something we are prepared to treat as the truth — the reference standard.1 For myocardial infarction that is the Fourth Universal Definition: a rise or fall in cardiac troponin together with clinical evidence of ischaemia (Thygesen et al. 2019).

This ordering matters. If you have no reference standard, you have no 2×2 table and no accuracy to measure — only agreement between two fallible measurements, which is a different question entirely.

Note what each column is doing. troponin_ng_L is the index test, the thing being evaluated. mi_confirmed is the reference standard. The remaining columns are patient characteristics we will use later to see whether accuracy holds up in different subgroups.

3 Turning a measurement into a result

Troponin is continuous. A 2×2 table needs a yes or a no. So we impose a threshold — here the conventional 99th-percentile upper reference limit of 14 ng/L.

1threshold <- 14
2cohort$test_positive <- cohort$troponin_ng_L >= threshold

3table(cohort$test_positive)
1
The cut-off, in ng/L. Changing this single number changes every measure in the course — which is the whole subject of Chapter 4.
2
>= produces TRUE or FALSE for each patient.
3
A quick sanity check before going further. 

FALSE  TRUE 
  378   222
The threshold is a decision, not a fact

Nothing in the biology of troponin makes 14 ng/L the right number. It is a choice about how willing we are to be wrong in each direction, and a different choice would give a different test. Treating a cut-off as though it were inherent to the assay is one of the commonest conceptual errors in diagnostic reasoning.

5 Reading the table

Learn these four names now; the rest of the course assumes them.

The margins matter too. The row totals are how many patients the test called positive or negative. The column totals are how many actually had the disease — 77 of 600 here, a prevalence of 12.8%.

Which way round?

Convention puts the reference standard in columns and the test in rows. Sensitivity and specificity are then read down the columns, predictive values across the rows. If you fix that orientation in your mind now, you will never have to re-derive which denominator a formula wants.

6 Three ways this table goes wrong

Partial verification bias

Only patients with a positive index test receive the reference standard. The FN and TN cells are then built from incomplete information, and sensitivity is inflated. Common wherever the reference standard is invasive, expensive or carries risk — coronary angiography being the obvious example here.

Incorporation bias

The index test is itself part of the reference standard. Troponin appears in the universal definition of MI, so a troponin-based index test is partly being compared against itself, and accuracy is overstated. Rarely avoidable; it must be declared.

Spectrum bias

Accuracy is estimated in a population unlike the one where the test will be used — florid inpatient cases versus undifferentiated primary-care presentations. Sensitivity and specificity are stable across prevalence but not across case mix, a distinction Chapter 3 returns to. The STARD statement exists largely to make these design features visible (Bossuyt et al. 2015).

7 Check yourself

A study enrols 500 patients. 60 have the disease. The test is positive in 48 of those 60, and positive in 35 of the remaining patients. How many true negatives are there?

Of the 440 patients without the disease, 35 tested positive, so 440 − 35 = 405 tested negative and did not have the disease. The 12 is the false-negative count (60 − 48), and 452 is the total number of negative tests (405 + 12).

A hospital introduces the same troponin assay in its outpatient chest-pain clinic, where far fewer patients turn out to have infarcted. Which of the following will change?

Sensitivity and specificity are conditional on disease status and are unaffected by how common the disease is. Predictive values are conditional on the test result and depend directly on prevalence — which is why the same positive result means something different in the clinic than in resus. Chapter 3 works through the arithmetic.
